# 东门1990开店日记

原生 HTML / CSS / JavaScript 餐厅经营小游戏，无需安装依赖或执行构建命令。

## 文件结构

- `index.html`：页面入口与游戏界面
- `game.js`：订单、计时、评分、通关及小红书容器适配逻辑
- `style.css`：基础游戏样式
- `overrides.css`：背景、横屏布局及兼容性优化
- `assets/`：像素图鉴与餐厅背景

## 屏幕适配

游戏使用固定 1365×768 横版舞台，并按屏幕可用宽高等比缩放。手机竖屏时保持横版画面完整居中，上下以黑边填充；横屏、刘海屏和小红书容器安全区会自动避让，不会裁切游戏内容。

## 本地运行

浏览器可以直接打开 `index.html`。若浏览器限制本地资源，可在本目录启动任意静态 HTTP 服务，例如：

```bash
python3 -m http.server 8080
```

随后访问 `http://127.0.0.1:8080/`。

## 部署与小红书小工具

- 普通静态网站：将本目录全部文件上传到静态托管服务。
- 小红书小工具：压缩本目录内容，确保 `index.html` 位于 ZIP 根目录。
- 小红书容器 API 均带能力检测；普通浏览器会自动使用兼容路径。
